# Микрофото — подготовка микрофотографий шлифов

Настольная программа для Windows. Обрабатывает снимки шлифов и аншлифов,
сделанные на телефон через микроскоп: обрезает кадр по полю зрения, делает
фон вне круга чёрным, повышает резкость, наносит масштабную шкалу и сохраняет
файлы под понятными именами (`1_Св-25-14_пп_10х.jpg`).
Исходные фотографии никогда не изменяются.

## Запуск (Windows 10/11)

Дважды щёлкните **`Запуск.bat`** в папке программы.

- При первом запуске файл сам создаст виртуальное окружение `.venv` рядом
  с программой и установит нужные библиотеки. Это займёт несколько минут
  и требует интернета. В следующий раз программа запустится сразу.
- Нужен Python 3.10 или новее (лучше 3.12) с сайта python.org. При установке
  отметьте пункт «Add python.exe to PATH».
- Если что-то пошло не так, окно не закроется: в нём будет видно, что
  случилось.
- Ярлык на `Запуск.bat` можно вынести на рабочий стол: программа запустится
  из любого места.

Запуск вручную, без `Запуск.bat`:

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

## Как работать

1. **Фотографии.** Выберите папку. Укажите название шлифа, освещение,
   увеличение и номер (кнопками 1–20; «＋5» добавляет ещё кнопки).
   Нажимайте Enter: следующее фото получит те же параметры, включая номер.
   Клавиши: `←` и `→` листают фото, `1`–`4` выбирают увеличение.
2. **Поле зрения.** Круг находится автоматически. Если он верный, нажмите
   Enter. Круг можно перетащить мышью. Радиус меняется колесом
   (с Shift точнее) или за край круга. `Ctrl` + колесо масштабирует просмотр.
3. **Готово.** Посмотрите результат и нажмите «Обработать и сохранить».
   Чтобы изменить резкость, шкалу или формат, откройте «⚙ Настройки»,
   затем нажмите «Пересобрать». Результат всегда создаётся заново из
   оригиналов.

Лишние фото можно убрать из партии: выделите их (Ctrl или Shift + щелчок)
и нажмите `Delete`, «Удалить из списка» внизу списка или «Убрать из проекта»
в меню по правой кнопке. Файлы на диске не удаляются, вернуть — `Ctrl+Z`.

В «⚙ Настройки → Обработка» задаются фон за пределами поля зрения
(чёрный или белый) и резкость 0–100: 50 — рекомендуемое значение.
Там же есть просмотр «До / После» в масштабе 100 %; пока удерживаете
пробел, видно оригинал.

Отмена и повтор: `Ctrl+Z` и `Ctrl+Y`.

Работа сохраняется автоматически отдельно для каждой папки. При следующем
запуске программа предложит продолжить. Разметка переносится только на те же
самые файлы: если фото заменили другим с тем же именем, оно считается новым.
Меню папки → «Начать заново» предлагает два варианта:
- «Закрыть и сохранить» — продолжить позже;
- «Начать новый проект» — удалить сохранённую разметку этой папки и начать
  с чистого листа. Фотографии на диске при этом не удаляются.

Кэш миниатюр и предпросмотра (`%LOCALAPPDATA%\MicroPhoto\cache`) очищается
автоматически: по умолчанию удаляется всё старше 30 дней и сверх 2 ГБ.
Настроить очистку или очистить кэш вручную можно в «⚙ Настройки → Хранилище».
Разметка проектов (`projects`) — не кэш, автоматически она не удаляется.
Журналы ошибок лежат в `%LOCALAPPDATA%\MicroPhoto\logs`.
